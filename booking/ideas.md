# 會議室預約系統 - 設計理念

## 選定設計方向：**現代極簡 + 實時協作**

### 設計運動
**Bauhaus 現代主義** - 功能優先，清晰信息架構，強調秩序與效率

### 核心原則
1. **一眼看清** - 所有房間預約狀態在單一視圖中即時呈現，無需點擊鑽取
2. **視覺優先級** - 房間狀態用顏色編碼（綠=可用、紅=已預約、灰=維護中），大字體時間槽
3. **無摩擦預約** - 點擊時間槽即可預約，自動分配房間邏輯透明化
4. **實時反饋** - 預約成功/衝突的即時視覺反饋，無延遲感

### 色彩哲學
- **主色** - 清爽藍 (`oklch(0.623 0.214 259.815)`) 代表可信、專業
- **成功綠** - `oklch(0.65 0.15 142)` 表示房間可用
- **警告紅** - `oklch(0.577 0.245 27.325)` 表示已預約
- **中立灰** - `oklch(0.85 0.01 0)` 用於背景與分隔
- **背景** - 純白 `oklch(1 0 0)` 確保最高可讀性

### 佈局範式
- **網格佈局** - 3 列（房間 A/B/C），多行（時間槽），類似日曆視圖
- **時間軸** - 左側垂直時間標籤，右側房間卡片堆疊
- **卡片式房間** - 每間房一個獨立卡片，內部顯示 30 分鐘時間槽網格
- **無滾動優先** - 一屏內顯示完整日期的所有房間

### 簽名元素
1. **時間槽卡片** - 圓角矩形，懸停時提升陰影，點擊時脈衝動畫
2. **房間標籤** - 大膽字體（700 weight），房間名稱 + 容納人數副標題
3. **預約徽章** - 小圓形標籤顯示預約者名稱/ID，浮在時間槽上

### 互動哲學
- **即時視覺反饋** - 滑鼠懸停時時間槽變亮，點擊時脈衝擴展
- **無模態對話** - 預約成功直接在卡片上顯示確認，無彈窗
- **撤銷友好** - 預約後 5 秒內可點擊撤銷，倒計時提示

### 動畫指南
- **時間槽懸停** - 100ms ease-out，背景色變淺 + 陰影提升
- **預約成功** - 200ms ease-out，卡片邊框閃爍綠色 3 次
- **時間槽進入** - 30ms 錯開，從上到下級聯顯示
- **無減速動作偏好** - 所有動畫 ≤ 250ms，尊重 `prefers-reduced-motion`

### 字體系統
- **標題** - Poppins 700（房間名稱）、600（時間標籤）
- **正文** - Inter 400（預約者名稱）、500（時間槽標籤）
- **副標題** - Inter 300（容納人數、房間描述）
- **層級** - 大標題 24px、卡片標題 18px、時間槽 14px、副文本 12px

### 品牌本質
**一句定位** - 為忙碌的團隊提供即時、無摩擦的會議室預約，讓協作更流暢。

**人格形容詞** - 專業、高效、友善

### 品牌聲音
- **標題** - 直接、行動導向："立即預約會議室"、"查看今日空房"
- **CTA** - 清晰、肯定："預約"、"確認"、"取消"
- **微文案** - 友善、簡潔："房間已滿，系統已自動分配 B 房"、"預約成功！"
- **禁止** - 避免模糊措辭如 "歡迎來到我們的系統"、"點擊此處開始"

### 品牌標誌
- **概念** - 簡化的日曆格子 + 房間門圖標，單色設計
- **風格** - 幾何、現代、可在 16px-256px 清晰顯示
- **位置** - 頁面左上角標題欄，32x32px 大小

### 簽名品牌色
**專業藍** - `oklch(0.623 0.214 259.815)` - 代表信任、效率、專業

## 技術實現細節

### 數據結構
```typescript
interface TimeSlot {
  id: string;
  startTime: string; // "09:00"
  endTime: string;   // "09:30"
  room: "A" | "B" | "C" | null; // 自動分配
  bookedBy?: string; // 預約者名稱
  status: "available" | "booked" | "maintenance";
}

interface Room {
  id: "A" | "B" | "C";
  name: string;
  capacity: number;
  slots: TimeSlot[];
}
```

### 自動分配邏輯
1. 用戶選擇時間槽
2. 系統檢查 A 房是否可用
3. 若 A 房已預約，檢查 B 房
4. 若 B 房已預約，檢查 C 房
5. 若 C 房已預約，提示"今日無可用房間"
6. 分配成功後，立即更新視圖

### 狀態管理
- 使用 React Context 管理全局預約狀態
- localStorage 持久化預約數據（無需後端）
- 實時更新所有房間卡片

### 響應式設計
- **桌面** (≥1024px) - 3 列房間並排
- **平板** (768-1023px) - 2 列房間，可橫向滾動
- **手機** (<768px) - 1 列房間，垂直滾動時間槽
